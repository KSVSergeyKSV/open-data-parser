# Конвертер открытых данных (МР 4.0)

## 📖 Описание

Локальное веб-приложение для подготовки комплектов файлов открытых данных для загрузки на портал data.gov.ru в соответствии с методическими рекомендациями версии 4.0.

### Ключевые возможности

✅ **Полная автономность** - работает без интернета, не требует установки  
✅ **Кроссплатформенность** - Windows, Linux, macOS  
✅ **Многопользовательский режим** - каждый пользователь имеет свой раздел  
✅ **Логирование действий** - аудит всех операций  
✅ **Сохранение разделов** - экспорт/импорт рабочих пространств  
✅ **Архив приказов** - хранение истории изменений  

## 🚀 Быстрый старт

1. Откройте файл `index.html` в браузере (Chrome, Firefox, Edge)
2. Создайте новый раздел или загрузите существующий
3. Пройдите 5 шагов мастера:
   - Загрузка приказа и реестра
   - Выбор набора данных
   - Загрузка файла данных
   - Формирование структуры и паспорта
   - Конвертация и скачивание ZIP

## 📋 Пошаговая инструкция

### Шаг 1. Создание раздела

При первом запуске:
1. Нажмите «➕ Создать новый раздел»
2. Введите название (например, «Бюджетные данные 2024»)
3. Раздел сохранится в localStorage браузера

Для возврата к существующему разделу:
1. Кликните по нужному разделу в списке
2. Или загрузите ранее экспортированный `.odsection` файл

### Шаг 2. Заполнение информации о пользователе

1. В боковой панели нажмите «✏️ Редактировать»
2. Укажите ФИО, отдел, телефон, email
3. Эти данные будут использоваться для автозаполнения паспорта

### Шаг 3. Загрузка приказа и реестра

**Приказ:**
- Загрузите файл приказа (.xlsx, .doc, .pdf)
- Это будет храниться в архиве как основание

**Реестр наборов ОД:**
- Формат: Excel (.xlsx, .xls) или CSV/TXT
- Обязательные колонки:
  - `id` или `ID` - идентификатор набора
  - `name` или `Наименование` - название
  - `owner` или `Владелец` - ведомство
  - `responsible` или `Ответственное лицо`
  - `status` - статус (active/Действующий или archive/Архив)
  - `description` или `Описание`

**Эталонная структура:**
- Формат: Excel, CSV, TXT или JSON
- Колонки:
  - `fieldname` или `name` - имя поля
  - `description` или `Описание`
  - `type` - тип данных
  - `required` - обязательность (да/нет)

### Шаг 4. Выбор набора данных

1. Используйте поиск по наименованию
2. Фильтруйте по владельцу и статусу
3. Кликните по строке таблицы для выбора
4. Проверьте информацию в панели выбранного набора

⚠️ **Внимание!** При выборе архивного набора появится предупреждение

### Шаг 5. Загрузка файла данных

**Поддерживаемые форматы:**
- Excel (.xlsx, .xls)
- Word (.doc, .docx) - извлекаются таблицы
- ODS (OpenDocument)
- CSV, TXT (автоопределение разделителя)

**Автоматические проверки:**
- Сверка столбцов с эталонной структурой
- Определение типов данных (string, number, date, boolean)
- Предварительный просмотр первых 5 строк

### Шаг 6. Формирование паспорта

**Вкладка «Структура данных»:**
- Автоматически сгенерированная структура
- Типы данных определены автоматически
- Описания подгружаются из эталона

**Вкладка «Паспорт ОД»:**
- Нажмите «🔄 Автозаполнение из реестра»
- Проверьте и дополните обязательные поля:
  - Идентификационный номер
  - Наименование набора
  - Описание
  - Владелец
  - Ответственное лицо
  - Телефон и email
  - Дата актуальности
  - Ключевые слова

- Нажмите «✓ Проверить паспорт»

### Шаг 7. Конвертация и скачивание

1. Выберите форматы выходных файлов:
   - ✅ CSV (обязательно)
   - ✅ JSON (структура + данные)
   - ⬜ XML (опционально)

2. Нажмите «🚀 Конвертировать и скачать ZIP»

3. Получите архив с файлами:
   - `data.csv` - машиночитаемые данные
   - `data.json` - данные в JSON (если выбрано)
   - `data.xml` - данные в XML (если выбрано)
   - `structure.json` - структура данных
   - `meta.json` - машиночитаемый паспорт (МР 4.0)
   - `meta.txt` - человекочитаемый паспорт

### Форматы данных

- **JSON**: UTF-8, pretty-print
- **XML**: UTF-8, декларация, иерархическая структура
- **structure.json**: Массив объектов с полями fieldname, description, type, required

## 📊 Логирование и аудит

Все действия пользователя записываются в журнал:

```json
{
  "timestamp": "2024-01-15T10:30:00.000Z",
  "action": "SELECT_DATASET",
  "details": "Выбран набор: DS-001 - Бюджетные расходы",
  "user": "Иванов Иван Иванович",
  "department": "Финансовый отдел",
  "ip": "local"
}
```

**Типы событий:**
- CREATE_SECTION - создание раздела
- ENTER_SECTION - вход в раздел
- FILE_UPLOADED - загрузка файла
- REGISTRY_PROCESSED - обработка реестра
- SELECT_DATASET - выбор набора
- PASSPORT_AUTOFILL - автозаполнение паспорта
- CONVERT_START - начало конвертации
- CONVERT_COMPLETE - завершение конвертации

Просмотр журнала: кнопка «📋 Журнал действий» в шапке

## 💾 Экспорт и импорт разделов

### Экспорт
1. Нажмите «💾 Сохранить раздел»
2. Скачается файл `.odsection` (JSON формат)
3. Передайте файл коллегам или сохраните в архив

### Импорт
1. На приветственном экране нажмите «📥 Загрузить раздел из файла»
2. Выберите `.odsection` файл
3. Раздел появится в списке с новым ID

## 🗄️ Архив приказов

При изменении приказа:
1. Старые данные переходят в исторический архив
2. Архив хранит:
   - Номер и дату приказа
   - Приложения к приказу
   - Дату упразднения
   - Новый приказ (если есть)

Это позволяет понять, почему данные были организованы определённым образом.

## ❓ Часто задаваемые вопросы

### Q: Где хранятся мои данные?
A: Данные хранятся в localStorage браузера. При очистке кэша данные могут быть потеряны. Регулярно делайте экспорт разделов!

### Q: Можно ли работать одновременно нескольким пользователям?
A: Да, если разместить папку на сетевом шаре. Каждый пользователь работает со своим разделом. Однако localStorage у каждого свой.

### Q: Как обновить приложение?
A: Просто замените файлы в папке на новые версии. Данные в localStorage сохранятся.

### Q: Что делать при ошибке «Недостаточно памяти»?
A: Разбейте большой файл данных на несколько меньших. Приложение оптимизировано для файлов до 10,000 строк.

### Q: Поддерживается ли работа с большими реестрами (1000+ наборов)?
A: Да, реализована пагинация (10 записей на страницу) и фильтрация.

## 🐛 Устранение неполадок

| Проблема | Решение |
|----------|---------|
| Не загружается файл | Проверьте формат, попробуйте пересохранить в Excel |
| Пустая таблица после загрузки | Проверьте названия колонок в исходном файле |
| Не работает поиск | Обновите страницу (F5) |
| Исчезли разделы | Проверьте, не очищен ли кэш браузера |
| Ошибка кодировки CSV | Сохраните файл в UTF-8 в текстовом редакторе |
